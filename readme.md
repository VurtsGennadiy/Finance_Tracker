# Трекер личных финансов

Современный пользователь обычно имеет несколько карт и счетов в разных банках. Цель приложения - облегчить учёт личных финансов,
собрать в одном месте все счета и расходы по ним. Проводить анализ расходов по категориям и планировать бюджет.

Основные возможности:
1. Создание счета
2. Удаление счёта
3. Перевод средств между счетами
4. Совместные счета
